= Korean MCQ Accuracy Benchmark

This module evaluates *language and knowledge accuracy* using Korean multiple-choice benchmarks (for example HAE-RAE, KMMLU, CLIcK) through EvalHub’s Korean MCQ provider. Results are tracked in MLflow so accuracy runs share the same experiment discipline as performance jobs.

== Learning Objectives

* Discover Korean benchmarks registered on EvalHub
* Submit a single-benchmark accuracy job
* Find accuracy metrics and artifacts in MLflow

== Key Concept: Same Job API, Different Provider

Accuracy jobs reuse `SyncEvalHubClient` and `JobSubmissionRequest`. Only the *provider* and *benchmark id* change:

[source,python,subs=none]
----
single_request = JobSubmissionRequest(
    name="haerae-eval",
    description="HAE-RAE benchmark - Korean language understanding",
    tags=["korean", "haerae", MODEL_NAME],
    model=model,
    benchmarks=[
        BenchmarkConfig(
            id="haerae",
            provider_id=KOREAN_PROVIDER_ID,  # discovered from client.providers.list()
            parameters={"temperature": 0.0, "max_tokens": 1024, "limit": LIMIT},
        ),
    ],
    experiment=ExperimentConfig(
        name="korean-haerae-eval",
        tags=[
            ExperimentTag(key="language", value="korean"),
            ExperimentTag(key="benchmark_suite", value="haerae"),
        ],
    ),
)

job = client.jobs.submit(single_request)
print(job.id, job.state.value)
print("MLflow experiment:", job.resource.mlflow_experiment_id)
----

[TIP]
====
Keep `LIMIT` small during the workshop (as set in `.env`) so jobs finish in class time. Full-dataset runs belong in longer offline evaluations.
====
