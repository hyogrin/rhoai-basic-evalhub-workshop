= Basic EvalHub on Red Hat AI

A hands-on showroom workshop for evaluation-driven LLM operations on {rhoai} {rhoai-version} using *EvalHub* and *MLflow*.

Participants learn why stochastic LLMs need systematic evaluation gates, run performance and accuracy jobs through EvalHub, unify results under shared MLflow experiments, and evaluate content-safety guardrails using the companion lab notebooks.

=== Local Development

==== Preview script (recommended)

[source,sh]
----
chmod +x scripts/preview-local.sh
./scripts/preview-local.sh            # live preview (podman → docker → npm)
./scripts/preview-local.sh build      # static build into ./docs
./scripts/preview-local.sh serve      # serve ./docs
./scripts/preview-local.sh stop       # stop preview container
----

Open http://localhost:8080 in your browser.

Optional environment variables:

* `PORT=8080` -- HTTP port
* `PREVIEW_ENGINE=auto|podman|docker|npm` -- force a runtime
* `OPEN_BROWSER=1` -- open the browser automatically (macOS)
* `SELINUX=1` -- use `:z` volume mount for SELinux hosts

==== Manual container command

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

For SELinux environments:

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora:z -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----
